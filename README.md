# Speech to Text Converter

## Description

A simple Flask web application that converts:

- Live microphone speech (browser)
- Uploaded audio files

into text.

## Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
- SpeechRecognition
- PyDub
- FFmpeg

## Features

- Live Speech Recognition
- Upload Audio File
- Convert Speech to Text
- Copy Text
- Download Text
- Clear Text
- Multi-language Selection

## Installation

1. Install Python
2. Install FFmpeg
3. Install dependencies

```bash
pip install -r requirements.txt
```

Run:

```bash
python app.py
```

Open:

```
http://127.0.0.1:5000
```
