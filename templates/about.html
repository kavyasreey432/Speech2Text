About Speech To Text Converter

A Flask-based web application that converts speech into text, converts text into speech, and allows users to manage their previous conversions through History.

Project Objective

The main objective of this project is to provide an easy-to-use platform for converting live speech and uploaded audio into text. The system also provides text-to-speech functionality, allowing users to enter or paste text and convert it into spoken audio.

Features

  • ✔ Live Speech Recognition
  • ✔ Upload Audio Files
  • ✔ Text to Audio Conversion
  • ✔ Multi-language Support
  • ✔ Copy Converted Text
  • ✔ Download Text
  • ✔ Download Speech as MP3
  • ✔ Pause and Resume Speech
  • ✔ Stop Text-to-Speech
  • ✔ Conversion History
  • ✔ Delete History Records
  • ✔ Clear All History
  • ✔ Responsive Interface

History Management

The History feature stores converted content from Live Speech, Upload Audio, and Text to Audio. Users can view their previous conversions in a table containing the date, conversion type, and converted text.


  • ✔ Live Speech History
  • ✔ Upload Audio History
  • ✔ Text to Audio History
  • ✔ Copy History Text
  • ✔ Delete Individual Records
  • ✔ Clear All History

Overall Workflow

User → Live Speech / Upload Audio / Text to Audio → Speech Processing → Text or Audio Output → Copy / Download → Save to History → History Management
